# Исходники создания моделей

В `scripts/` находятся авторские Python-скрипты базового карьера, техники, текстур, экспорта и проверок. Это архив инструментов, которыми создавалась сцена; он не исполняется при запуске веб-приложения. Готовые runtime-модели уже лежат в `../dist/assets/`.

Исходный пайплайн использовал Blender, NumPy/Pillow и инструменты сжатия glTF. Скрипты рассчитывают пути относительно своей папки, создают выходные файлы и в отдельных шагах ожидают `.blend` от предыдущих шагов. Промежуточные `.blend`, резервные копии и установленные инструменты разработки в пакет не включены. Поэтому архив не является заявлением о проверенной автоматической пересборке всех моделей одной командой.

Для воспроизводимого запуска конкурсного приложения используйте готовые модели и команду из корневого README. Веб-код не минифицирован и может редактироваться непосредственно в `dist/`. Для отдельной генерации нового горного окружения предназначен `../scripts/build_mountain_worlds.py`; для его запуска нужен Blender. Перегенерация моделей не требуется для игры или Node-тестов.
